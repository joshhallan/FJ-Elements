# Changelog

All notable changes to this project will be documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

---

## [1.1.0] - 2026-07-17

### Added

- Added `count` support to Skeleton components.
- Added reduced motion support for animated components.
- Improved component accessibility coverage.

### Changed

- Updated design tokens to the latest naming convention.
- Refactored Toast provider architecture.
- Improved Modal implementation using native dialog behaviour.
- Removed unnecessary interactive behaviour from ProjectCard.
- Updated navigation after removing layout dependencies.

### Fixed

- Improved Alert intent colour consistency.
- Fixed accessibility issues across interactive components.
- Improved Storybook examples and component documentation.
